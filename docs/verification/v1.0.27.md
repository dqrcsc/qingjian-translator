# v1.0.27 发布验收

基线：v1.0.26 / af32362。

## 问题与修复路径

1. **译图控制条常驻遮挡图片**：原实现中 `.ig-img-control-bar` 在图片进入视口（`IntersectionObserver`）或完成原位译图后以 `opacity: 0.9` 常驻在宿主容器右上角，鼠标移出图片后不会收起。现改为默认 `opacity: 0; pointer-events: none; backdrop-filter: none;`，通过捕获阶段指针命中测试（覆盖目标 `<img>`、控制条、原位覆盖层热区、双语对照抽屉及 `[data-testid="tweetPhoto"]`）按需切换 `.is-visible`，并在指针移出图片边界、`documentElement` `mouseleave` 或 `window` 滚动离开图片框后立即隐藏。
2. **鼠标点击按钮后的焦点残留**：将 `:focus-within` 替换为 `:has(:focus-visible)`，同时在 `translateImageElement` 请求期间设置 `data-loading="1"`（`finally` 释放）。键盘 Tab 聚焦和翻译加载期间保持可见，鼠标点击触发译图后移出图片可正常隐藏。
3. **宽容器与多图容器定位隔离**：新增 `syncImageControlBarPosition` 按目标 `<img>` 相对宿主容器的实际坐标计算 `top` / `right`，并为共享父容器内的每张合格图片创建独立控制条（`bar._igOwnerImg = img`），鼠标移入 `<figcaption>` 或容器空白区不再误显示图片按钮。
4. **生命周期与设置联动清理**：`invalidateChangedImageSource` 重建图片控件时沿用当前悬停状态；`releaseImageControls` 移除当前悬停控件时抑制静止光标下的合成 `mouseover` 误唤醒；`applyUpdatedSettings` 在 `enableImageTranslate === false` 时统一移除页面译图控制条、覆盖层与对照抽屉。

## 远端回归修正

首次 `main` CI 在 Linux Chromium 的连续开关页面翻译用例中偶发触发帧级重排竞态：开启页面翻译时上方段落译文把图片下推脱离静止指针（`activeHoveredImage` 置空），紧接着关闭页面翻译移除段落译文与图片控件后，图片重新上移回到静止指针下方，且 `PointerEvent` 浮点坐标与 `MouseEvent` 整型坐标存在 `<= 1px` 舍入差，触发浏览器重排 `mouseover` 重新挂载控件。修正 `releaseImageControls` 在释放任一图片控件时记录当前指针抑制点，允许 `<= 1px` 浮点/整型坐标容差，并在真实 `pointermove`（`> 1px`）时立即恢复同图悬停检测；同时在 `tests/content-lifecycle.test.mjs` 补充对应回归断言。
