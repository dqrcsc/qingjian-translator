# v1.0.9 后续修复：YouTube 扩展连接恢复

基线：v1.0.9 / efd3769。日期：2026-10-30。

用户在重新加载扩展后保留了旧 YouTube 标签页，看到“字幕返回为空，已暂停”与“正在极速翻译”同时存在。刷新真实视频页后译文恢复，确认本次触发条件是旧内容脚本的扩展上下文失效。

修改仅涉及字幕请求错误分类与显示状态：失效上下文提示刷新，不反复请求；有效连接的模型/网络错误保留真实原因；浮层区分等待、执行、退避、暂停和需要刷新。字幕取消与其他消息容错语义保留。

验证：

- `npm run verify`：47 项结构检查、98 项 Node 测试通过。
- `npm run test:browser`：57 组通过，Chromium 148.0.7778.96，未捕获页面/CSP 异常。
- `tests/youtube-state.test.mjs`：5 项先失败后通过，覆盖 runtime 不存在、connect 拒绝、空连接响应、失效后停止与刷新动作、状态转换。
- `scripts/verify-content-browser.mjs`：完整轨道和实时原生字幕两路注入 connect 失效，确认无模型 HTTP、显示刷新，点击后实际页面重载并返回译文。既有 401/503 回归检查浮层不再显示加载。
- 浏览器测试仅使用本地接口；用户真实页面另观察到刷新后英文原文下出现对应中文，未更改模型设置或读取密钥。

本次未改变 manifest 版本，未覆盖已发布 Release。其他审计发现不混入本修复：启动配置竞态、桥接层晚到字幕归属、配置变化后旧译文保留、EPUB 结构抽取等另列优先级事项。
