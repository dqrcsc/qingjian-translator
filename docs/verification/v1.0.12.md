## 关键边界

- 全部网络模型测试使用本地模拟接口；音频使用合成数据与受控媒体时钟，不需要麦克风、不上传私人内容、不消耗付费模型配额。没有宣称验证真实模型质量或所有线上 YouTube 变体。
- 单页像素和 8 槽位限制约束应用驻留画布（理论 RGBA 128 MiB），不包括取消任务短暂重叠、PDF.js 内部内存、JPEG、译图、全文及备份。两个无法立即取消的底层任务仍未结束时会明确报错；永久挂起可能需要重新打开文档。
- 阅读窗口只限制挂载内容；完整模型仍保留，全文导出仍会临时生成完整 DOM。上一版译文只保留在当前工作台内，关闭或替换文档前应导出。
- 文档绑定模型不自动进行 Gemini 404 模型切换；这是防止不同页面混用模型的有意取舍。
- 延续 90 秒导入预算、100 MiB 输入及 EPUB 解压配额；未升级 PDF.js（仍为 6.4.299），没有提交 Chrome Web Store 审核。
