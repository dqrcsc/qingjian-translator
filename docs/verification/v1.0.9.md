## 全宽阅读与打印

- 三种视图：双语对照、仅译文（保留左栏）、全宽仅译文。全宽折叠左侧原文栏；未译段落保留原文并显示提示。
- 真实控件切换与 MD / HTML / EPUB 下载验证纯译文输出；切换视图不发起模型请求，恢复双语后原文可见。
- PDF 导出实际入口覆盖“仅已译页”、指定范围、全宽视图与筛选恢复。测试用打印媒体样式和拦截 `window.print` 检查进入打印时的 DOM，不自动操作系统打印对话框。
- PDF 重译不提前消耗整篇请求：先处理两页，后续页滚动或继续时仍保留强制重译意图。

## 使用与验证边界

- 模型接口为受控本地模拟，未调用付费供应商；不代表真实模型翻译质量与服务可用性。
- 网页链接文字保留原文，周围正文翻译；仅允许 HTTP(S)、邮件、电话以及解析后属于这些协议的相对/锚点链接。
- HTML 导出包含全部已载入文档内容。未解析 PDF 页只有明确缺页说明，不包含原页，也不会在 HTML 导出时自动补译。MD/EPUB 仍导出已解析块。
- SRT/TXT 按菜单固定输出双语字幕；PDF 使用独立弹窗选择视图和页码范围。
- 浏览器快捷键覆盖页面键盘事件与实际内容消息入口；不穷举各操作系统的全局快捷键拦截行为。
- PDF 不保证像素级还原；EPUB 是重建的文本版本。长文档下载/解压限额、离屏 PDF 图片回收不在本版范围。
