## 使用边界

- 浏览器加载真实 manifest、后台及 UI 入口；模型接口为本地模拟，网页、文档和图片为合成数据。Gemini 测试验证原生请求和响应处理，不代表真实付费模型翻译质量认证。
- 更改有效翻译配置后网页需手动重新开启翻译；不会自动全页重译。无效多模态业务结果等待明确重试，不进行无限自动恢复。
- 本轮解决零有效字幕条目误报成功；部分损坏字幕中的有效条目仍按既有方式解析，未新增逐条损坏诊断。
- 本版不新增长 PDF 右栏虚拟化或图片资源预算，不新增运行依赖，没有提交 Chrome Web Store 审核。

远端结果以 [GitHub Actions](https://github.com/dqrcsc/qingjian-translator/actions/workflows/verify.yml) 和 [v1.0.14 Release](https://github.com/dqrcsc/qingjian-translator/releases/tag/v1.0.14) 中附带的提交与 CI 运行链接为准；发布前不预填远端成功。
