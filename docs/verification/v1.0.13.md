## 使用边界

- 本轮模型接口均为本地模拟，所有文档/图片/网页为合成数据，不验证付费模型质量或所有线上 YouTube/复杂编辑器变体。
- PDF 当前页无可提取文本时不会自动切换模型或拿别页文本补齐。单请求重试用尽后，工作台失败页等待明确重试，不进行无限自动恢复。
- HTML 解析保留正文，不还原原网页布局，不加载外部样式计算可见性；排除显式 hidden/aria-hidden 和内联隐藏样式。导出双栏规则针对工作台重排结果。
- 非 PDF 图块标签与图注分别判断完成；原文标签可复用，缺少标签才请求图像识别。上一版备份只保留在当前工作台生命周期。
- 延续既有 PDF 像素、导入预算和阅读窗口边界；本次未把右栏全部数据或整个浏览器进程宣称为固定内存。
- 没有提交 Chrome Web Store 审核。
