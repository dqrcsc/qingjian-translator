# v1.0.23 验收记录

日期：2026-11-06。基线：v1.0.22 / `af13313fe2a5b917f1f7c70c04e6202c442e80c8`。

## 原问题与修复

1. **完整浏览器回归失败**：v1.0.22 的 GitHub CI 在 `verify-studio-browser.mjs` 的乱序 PDF 翻译入口等待第 2 页完成时超时。该页使用正常 `/Rotate 90`；提取器把视口变换后的 `rotated` 文字全部过滤，导致无可翻译内容。修复后保留正文，只保留明确的页边界和 arXiv 编号过滤。回归明确断言原文 `Rotated page` 存在，未放宽超时或跳过断言。
2. **表格标题误判**：真实坐标 PDF 的 `Method` 表头命中章节关键词，表格提取提前结束。对表格范围内同基线的分列单元格进行判断，保持表头、数据单元格和表后段落。
3. **公式重复**：本地公式不会交给模型翻译，但其译文字段为空，导致纸张双语视图两次渲染原文。现在公式/代码记录保留原文状态，使显示去重和导出状态一致。
4. **导出样式缺失**：独立 HTML 未带上根号、上下标组合、数学字形与作者卡片样式。补齐对应 CSS，实际下载后在屏幕和打印媒体中验证。
5. **说明与版本漂移**：README/CHANGELOG 停留在 v1.0.18，Gemini PDF 路径说明过时，lockfile 版本也仍为 1.0.18。同步版本摘要、实际协议路径、分批与预算边界，增加 manifest/package/lockfile 一致性检查。

## 验收范围

- `npm run pack`：48 项检查、226 个 Node 测试；运行文件清单、ZIP 文件内容、间接模块及许可证完整性校验。
- `npm run test:browser`：169 项完整浏览器回归通过，页面/CSP 异常为零；结果记录于 `dist/browser-verification/results.json`。远端结果见该发布提交的 GitHub CI。
- 新增 `tests/academic-pdf-fixture.mjs`：原创矢量 PDF，包含真正的上下堆叠分子/分母、Symbol 根号、字号变化下标、右侧公式编号、三列数据及表后正文。
- 新增 `scripts/verify-vector-academic-browser.mjs`：上传实际 PDF，分别使用 OpenAI 兼容与 Gemini 原生协议。模型只翻译输入文字，不生成公式或表格结构；断言请求发出前表格已结构化，公式未进入翻译请求。
- 检查双语和全宽纯译文；实际下载 HTML 后重新加载，核对单元格内容与对齐、分式/根号横线、下标、编号和正文；切换布局及导出不产生额外翻译请求。
- 通过实际 PDF 导出菜单和确认按钮进入打印，生成 PDF 文件，再用内置 PDF.js 重新读取输出，确认公式、表格及表后正文存在。
- 原 Gemini 多模态六列表格回归继续运行，新增作者卡片在工作台、HTML 与打印媒体中的布局检查。
- 最终 ZIP 解压到隔离目录，独立 Chromium 加载扩展：版本 1.0.23、后台、弹窗、设置和工作台三个入口通过，页面异常为零。
