# v1.0.24 验收记录

日期：2026-11-07。基线：v1.0.23 / `662d1d7d1ffdf9a302182b7cde37ea3eb313e645`。

## 七类修复与入口证据

1. **规则表格空单元格**：取消仅凭空值合并前两行的启发式，不再填入虚构横线。Node 覆盖空表头、首数据行第 1/2 列为空、原始横线及分行表头；实际上传 PDF 后核对请求前表格、浏览器单元格、下载 HTML 和打印媒体。
2. **混合 PDF 位图图中文字**：原创 PDF 同时包含丰富正文文字层和真实嵌入 JPEG 图表。OpenAI 兼容与 Gemini 原生协议均验证正文文本路径、单图视觉请求和导出标签。模拟不支持视觉的 400，正文和原图保留，状态及 HTML 标出未完成；单图重试只增加一个图像请求，不重译正文。图框和文字识别仍是尽力处理，未声称覆盖全部混合矢量/位图图表。
3. **失败页面请求组**：页面拥有独立请求 scope。实际 PDF 在并发 1 和 3 时首批返回 401，其余 HTTP body 保持在途；验证页面报错后不再启动批次、连接被取消、手动重试完成。原有端到端取消测试继续检查其他 scope 存活、队列释放、响应体中止及不缓存失败。新增旧文档页面 finally 不删除新文档同页 Promise 的测试。
4. **裸公式渲染**：命令名和环境名不计作自然语言单词。Node 覆盖裸/带定界符分式根号、矩阵及普通中英文说明；Gemini 原生响应经实际 PDF 入口后核对公式节点，下载 HTML 后检查打印媒体根号横线。
5. **父域继承规则**：实际网页抽屉处理器与工具栏弹窗分别取消继承规则，检查持久化结果、刷新与兄弟子域。界面明确展示继承来源及取消将影响其子站点；会话暂停的原有完整浏览器回归保留。
6. **重连剩余预算**：真实 request-client/service-worker 测试验证断连重放仍沿用首次起点；配置 30 秒、模拟已用 25 秒时仅剩约 5 秒，过期重放不再调用模型。另执行未缩放计时器的墙钟探针：第 25 秒断连，客户端在 30,002 ms 返回失败；v1.0.23 相同探针为 35,080 ms 后成功。
7. **功能说明一致性**：同步 README、工作台空态及导出弹窗、设置预算说明、商店记录和隐私说明。保留尽力重排、图级视觉模型要求、正文页计数与图中文字状态、父域规则作用范围、协议认证方式等边界。

## 验证边界

所有模型接口均为本地模拟服务，浏览器使用隔离资料目录，不读取用户真实 API Key。验证内容提取、协议、取消、状态、阅读和导出一致性，不代表真实模型翻译质量或任意论文版式均已验证。

保留原有真实打印导出入口、生成 PDF 并用内置 PDF.js 重新读取的回归；不自动操作系统打印对话框。不提交 Chrome Web Store 审核。
