## 验证结果

- `npm run pack`：46 项检查、39 项 Node 回归通过；ZIP 内 233 个运行文件通过逐文件内容、资源、版本与许可证检查。
- `npm run test:browser`：真实 MV3 扩展通过；本地 Chromium **148.0.7778.96**。保留 PDF Worker、标准字体、旋转页、矢量/JPEG2000 渲染及工作台/页面/弹窗取消检查，新增 3 组内容脚本验收。
- 浏览器回归操作真实 Manifest 注入的内容脚本、存储事件、网页 DOM、后台请求和 YouTube 音频按钮。CDP 只控制 RAF/IntersectionObserver 回调顺序、图片加载完成回调及模拟音频捕获入口，没有暴露生产测试接口或直接调用业务私有函数。
- 原始设置矩阵在修复前确认失败，修复后通过；代码质量与功能约定复核未发现阻塞发布问题。

## 边界

所有模型请求使用模拟数据或本地 HTTP 服务，无真实 API Key 或付费模型调用。YouTube 页面由本地 fixture 响应，音频捕获返回无音轨的测试流：此项验证协议准入及捕获入口，不证明真实录音、模型听译或第三方站点兼容性。

历史累计统计保留，不清空用户数据；无法仅凭已有总数还原过去重复计算的段落。`batchRetries` 统计子集补译批次数；`totalRequests` 沿用应用级估算口径，不是完整 HTTP 尝试或服务商计费次数。

HTTP 取消不能保证服务商停止计算或退费，复杂 PDF/EPUB 的既有边界不变。解码任务可能继续到完成，但失效结果不再提交到界面。

## 复现

```sh
npm ci --ignore-scripts
npx playwright install chromium
npm run pack
npm run test:browser
```

可用 `CHROMIUM_EXECUTABLE` 指定本地兼容 Chromium。本地原先缺少 Playwright 默认浏览器版本，因此使用已有的 148.0.7778.96；CI 使用锁文件对应 Playwright 安装的 Chromium。报告写入忽略提交的 `dist/browser-verification/results.json`。
