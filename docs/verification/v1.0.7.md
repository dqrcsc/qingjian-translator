| 问题 | 实现 | 验收 |
|---|---|---|
| F1 外部网页静默调用工作台 | studio HTML 不再公开为 web-accessible resource | 外部 iframe/顶层导航不能打开或触发下载、模型请求；真实 OPEN_DOCUMENT_STUDIO 后台入口能正常加载 PDF |
| F2 文档 ID 重排导致错译 | 单调块 ID；解析提交分配新身份；响应校验块对象、原文及版本；附图校验原目标对象 | 延迟批次期间插图，UI 与实际 Markdown 导出保持对应；PDF 页乱序合并不改旧 ID；替换页拒绝旧重译；解析中插图与迟到附图的原函数回归 |
| F3 字幕永久错误无限重发 | 永久错误停止；暂时错误 3 次会话尝试，1s/2s 退避；重试与设置变更恢复 | 已加载字幕轨道和原生实时字幕：401 播放/暂停均只发送一次；持续 503 最多 9 次 HTTP；旧视频迟到结果隔离；首页往返同视频恢复 |

| F7 清理后悬停按钮失效 | 释放控件同步清 hover 所有权标记 | 关闭网页翻译再悬停，恰好恢复一个可用按钮 |

## Gemini 原生协议

`tests/gemini-native.test.mjs` 共 8 项，覆盖：

- generateContent 真实请求格式和 candidates/content/parts 文本合并。
- 只保留非 thought 文本；纯 thought 输出拒绝。
- batch ID 校验与缺失子集补译。
- 图片、音频、PDF inlineData MIME 与字节保留。
- promptFeedback 阻断、空候选、SAFETY、MAX_TOKENS 均失败，不写成功缓存。
- 模型列表分页、generateContent 能力过滤、models/ 前缀处理。
- 401 不重试，错误中的测试密钥脱敏。

真实弹窗另覆盖成功文本、401、SAFETY、失败后恢复和模型发现配置归属。所有模型调用均为本地或受控 fixture，未调用付费服务。

## 复审收敛

跨模块复审额外捕获并修复：统计取消后晚写覆盖；存储立即失败丢弃成功译文；快速服务商切换显示旧模型；YouTube 离开视频后返回同一视频遗留 busy；解析期间插图导致 ID 复用及附图目标替换。上述场景已纳入回归。

## 使用与验证边界

- 统计是应用估算，不是账单；慢存储下可能延迟，队列饱和时会少记。已开始的本地写入不能回滚，但物理写保持串行，不会用旧写覆盖后续写。
- 字幕 3 次会话尝试与后台每次最多 3 次 HTTP 尝试是不同层次。持续 503 的测试上限为 9 次 HTTP，401 没有自动会话重试。
- 图片换源使旧结果失效，未增加逐图片独立网络取消；共享页面请求仍受现有总预算和页面取消约束。
- 浏览器回归使用受控 YouTube 页面和本地接口，不代表真实供应商服务质量、付费额度或真实 YouTube 网络可用性。
- 保留此前 PDF/EPUB 的版式与资源边界；大文件下载限额、EPUB 解压上限和长 PDF 显示内存上限未纳入本版。
