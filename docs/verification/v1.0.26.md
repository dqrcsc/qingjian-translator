# v1.0.26 发布验收

基线：v1.0.25 / a6afbeb。审计输入：`docs/reviews/v1.0.25-2026-11-13.md`，其中复现证据保留于同目录 `v1.0.25-audit/`。

## 五项问题与验收路径

1. **打印页范围竞争**：独立 `documentPrintSnapshot` 只渲染确认页。打印节点移除阅读节点 ID，后台按 ID 更新不会命中快照。实际上传九页 PDF，挂起第九页请求，确认仅打印第一、二页后释放为成功或失败，同时点击 HTML 下载；重开生成 PDF 验证只含第一、二页。
2. **附图伪装为整页完成**：MD/EPUB 完成范围复用 `translatedPages`，HTML 附图页显示正文未完成。实际上传未处理 PDF 再附图，三种下载保留未译正文提示，进度保持 0/1。
3. **非中文短标签丢失**：去掉中文目标语言特殊条件，以文字与数字/符号区分。实际西语、日语、阿拉伯语图片上传、重试和 HTML 下载保留三个短标签；节点测试覆盖纯数字、重复区域及短缩写。
4. **划词异常伪成功**：两种协议先校验译文、语境解释和拆解字段再计成功统计。真实选区请求空对象显示错误，成功段落/字符不增长，点击错误卡片重试可恢复；节点测试补充空数组、null、字段类型错误和无效 JSON。
5. **Gemini 原生标签上限**：真实稀疏 PDF 走原生视觉入口，检查发出的提示词没有最多 10 条/仅英文限制；10、11、20 标签均保留至阅读及 HTML。

## 资源与交互

- 一次字幕下载及格式回退共用 90 秒 / 8 MiB；实际流字节和头部声明均检查，同轨道并发合并。节点测试验证恰好上限、多一个字节、缺失/错误 Content-Length、回退累计、慢流取消、导航取消和播放器原响应不受副本取消影响。
- MAIN-world 真实字幕 HTTP 超限显示可见状态，重复提取不增加网络请求，手动重试恢复完整时间轴。
- 120 条真实原生 PDF 标题只挂载 100 个目录项，可翻至最后 20 项并点击定位。
- 真实 17 页 PDF 页组按钮及组号输入分别同步页码至 9、17，右侧每组最多 8 页。
- HTML 使用脱离页面的容器生成；打印只构建范围页，图片准备共享独立的 10 秒等待预算，避免与已取消的翻译请求组绑定。
- 打印等待图片期间阻止重复导出；实际替换 PDF 后移除旧快照，迟到图片不触发旧文档打印。
- 既有全篇九页打印、范围打印、表格公式与 HTML/EPUB 导出检查继续保留，打印检查改为读取实际打印快照。
