# 请求总时间预算与长网页资源回收验收

日期：2026-10-23。基线：v1.0.5 / `96944dd`。本轮仅推送源码优化，未创建新版本或替换 v1.0.5 Release 安装包。

## 行为与验证

| 优化 | 行为 | 验收证据 |
| --- | --- | --- |
| 端到端总时间预算 | 后台接收请求时开始计时；默认 90 秒，设置可调 30–300 秒；单次尝试仍最多 45 秒 | 预算归一化、已消耗时间不重置、成功后清理计时器；真实设置页保存并重载验证 120、1→30、999→300、空→90 |
| 排队与网络共享预算 | 排队、图片下载、响应体读取、重试等待、404 接口回退及子集补译使用同一取消信号 | 真实后台 Port 队列超时不发送 API、也不取消另一活动请求；backoff 不发下一次；fallback/subset 进行中到期被终止；legacy 图片下载入口同样超时 |
| 超时结果可恢复 | 返回 `timedOut: true`、`cancelled: false` 与中文报错；主动取消语义不变 | Chromium 真实 Port + 本地 HTTP 流式阻塞响应体：到期连接关闭、无额外重试，同一输入可再次请求且不是缓存命中；非协作迟到 fetch 不写缓存/成功产出统计 |
| 段落记录回收 | 成功、失败时删除内部记录；节点移除时解除观察、清队列及相关引用 | Node 验证成功/错误/重试、关闭翻译清理扫描计时器及根集合；浏览器 5 轮 × 50 段完成后每轮内部段落记录为 0 |
| 动态长网页 | 动态扫描使用单个 50ms 定时器，根集合超过 100 个合并至 document.body；移除后跳过扫描 | Node 验证突发新增的集合上限与离线根过滤；Chromium 200 个屏外观察目标移除后为 0 |
| 移动、移除及重插 | 同步搬移不误判删除；移除后迟到结果不写 DOM；重插可重新翻译 | 浏览器验证已译节点同步搬移、flush 前移除、活动请求中移除、迟到回包无写入、原节点重插后成功翻译；活动记录测量先为 3，移除后为 0 |
| 图片控件释放 | 移除图片即释放对应按钮/覆盖层/抽屉及双向 WeakMap 归属；挂载时检查旧 owner | 浏览器保留 figure 宿主只替换 img，旧按钮断开，新按钮正确翻译新图且仅出现一组控件/覆盖层；Node 验证回收前后两种挂载顺序 |

## 执行结果

- `npm run pack`：**47 项结构/功能检查、54 项 Node 回归全部通过**；ZIP 内 **234 个运行文件**通过逐文件内容、资源引用、版本与许可证检查。
- `npm run test:browser`：真实 MV3 扩展，本地 Chromium **148.0.7778.96**；保留既有 PDF Worker/渲染、工作台/弹窗取消、40 段快速开关、图片解码取消与 YouTube 协议准入回归。
- `git diff --check` 通过。Standards 复核无行动项；Spec 复核发现“保留图片宿主时旧按钮仍引用旧图”，修复后原复现和回归通过，无剩余阻塞问题。
- 浏览器原始结果保存在未提交的 `dist/browser-verification/results.json`，运行 `npm run test:browser` 可重新生成。

## 验证方法与边界

所有模型响应均为模拟数据或本地 HTTP fixture，不使用真实 API Key 或付费调用。真实入口测试只加速 30 秒预算计时器，不改变生产代码，也不加速原有 45 秒单次尝试超时；此项证明控制流及取消传播，不是实际等待 30 秒的性能基准。

浏览器通过 CDP 查询真实内容脚本的 Map 实例，并统计其 DOM 段落记录；观察器测试包装原生 observe/unobserve/disconnect 来核对目标集合。没有生产调试接口，也没有以固定堆内存值证明整个浏览器无泄漏。页面保留的译文 DOM 不会被删除，直到用户关闭翻译或页面移除节点。

已有混合批次不会因其中一个段落移除就整体取消，其他仍连接的段落可继续完成；已移除段落不再接受结果。图片解码可能继续到完成，但失效结果不再提交。单次预算针对后台请求，不包含用户输入等待、整篇文档总时长或前端图片解码时间。浏览器挂起/事件循环暂停时，定时器也受调度限制。

预算可结束客户端等待，并阻止到期后到达的模型结果继续提交缓存/界面；预算前已开始的缓存或统计存储写入可能继续完成，不承诺跨存储事务回滚。HTTP 中止不能保证外部服务商停止计算或退费。

## 复现

```sh
npm ci --ignore-scripts
npx playwright install chromium
npm run pack
npm run test:browser
```

本地可用 `CHROMIUM_EXECUTABLE` 指定已有兼容 Chromium；GitHub Actions 使用锁文件对应 Playwright 安装的 Chromium。
