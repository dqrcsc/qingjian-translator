# 青简 · 译读 v1.0.9

本版修复 v1.0.8 功能一致性复查发现的 7 个问题，并增加工作台全宽纯译文阅读模式。

## 修复

1. **多段内容不再提前消失**：仅译文模式只隐藏已有可用译文对应的原文，正在等待、失败或无需翻译的内容仍然可读。
2. **HTML 全文导出**：搜索或切换 EPUB 章节后导出 HTML，仍包含完整文档，不再静默遗漏其他段落。
3. **文档就绪检查**：解析完成前不能启动翻译或导出；导入失败、切换文档和迟到解析结果均有状态保护。
4. **PDF 强制重译**：全文和单页重译绕过文本与图中文字缓存并更新结果；继续翻译未完成页仍保留缓存命中。
5. **仅译文链接可用**：保留原链接文字和安全目标地址，周围正文翻译为目标语言；不复制原网页内联事件，也不让模型生成链接地址。恢复原文后保留原链接。
6. **Alt 操作互斥**：单键悬停操作与 Alt+A / Alt+S 组合区分，切换样式不再先撤掉当前段落译文。
7. **Markdown 代码完整性**：文末未闭合代码围栏保留到文档和导出中。

关联修复：PDF 打印“仅已译页”和指定页码范围不再混入范围外页面。

## 全宽纯译文阅读

工作台顶部可选择双语对照、仅译文（保留左栏）、全宽仅译文。全宽模式折叠左侧原文栏，让译文使用更大的阅读区域，切回双语即可恢复。未翻译的段落会保留原文并提示状态；切换视图本身不调用模型。

HTML 默认导出全部已载入文档内容，不受搜索/章节过滤；尚未解析的 PDF 页保留明确说明，不自动补译。MD / HTML / EPUB 使用当前纯译文或双语模式，未译内容保留原文；SRT / TXT 仍按菜单导出双语字幕。PDF 在独立弹窗选择模式和范围，通过浏览器打印保存。

## 安装与升级

下载附件 **qingjian-translator-v1.0.9.zip** 并解压。打开 Chrome 的 `chrome://extensions`，启用“开发者模式”，选择“加载已解压的扩展程序”，选中含 `manifest.json` 的目录。

已有用户覆盖原扩展目录后点击“重新加载”，刷新网页/视频和文档工作台标签页。无须卸载；浏览器中的配置与历史统计保留。请先导出未保存的工作台内容再刷新。
