# 青简 · 译读 v1.0.7

本版集中修复 v1.0.6 全面复查确认的 9 个问题，重点防止非预期模型请求、文档译文错位，以及异常后的持续重试或卡住。

## 修复内容

1. **工作台入口安全**：外部网页不能通过隐藏 iframe 或页面导航打开工作台并自动消耗用户模型额度。扩展自身打开文档的正常流程保留。
2. **文档译文归属**：插入图表、异步文档解析、PDF 页面乱序完成或替换后，块 ID 不再随显示顺序重排，迟到响应不能写进其他段落。
3. **字幕失败控制**：认证等永久错误停止自动请求；暂时错误最多进行 3 次会话尝试，按 1 秒、2 秒退避，显示原因并提供重试。视频切换和离开后返回同一视频可以恢复。
4. **统计与并发恢复**：统计读取卡住时可退出等待，已启动的写入保持串行，避免旧写覆盖新统计；存储异常不再丢弃成功译文或长期占用并发槽。
5. **服务商切换**：旧服务商迟到的模型列表不能覆盖当前配置；设置页和弹窗都检查响应归属，快速切换及跨窗口保存保持一致。
6. **图片来源更新**：同一 IMG 更换 src/srcset，以及响应式 currentSrc 变化，都会使旧译图和旧请求结果失效。
7. **图片悬停控件恢复**：关闭网页翻译后，再次悬停图片仍能显示一个有效的译图按钮。
8. **单段重译失败反馈**：失败或取消后保留已有译文，显示原因并恢复操作，不再一直显示“正在重译”；重复点击不会重复发送。
9. **缓存清理状态**：磁盘缓存不可用或清除失败会明确提示，不再误报“已清空”。

## Gemini 与回归测试

新增 Gemini 原生请求与响应测试，覆盖文本、子集补译、图片/音频/PDF inlineData、模型列表分页、401 脱敏，以及阻断和截断响应。仅有 thought、SAFETY 或 MAX_TOKENS 的结果不会作为成功译文写入缓存。

真实 Chromium 回归覆盖外部入口阻断、正常文档打开、并发插图及导出、字幕播放/暂停失败、动态图片来源、配置竞态、缓存故障和统计超时恢复。**47 项检查、80 项 Node 测试、37 组浏览器回归和 234 个 ZIP 运行文件校验全部通过**。具体环境见 [验收记录](https://github.com/dqrcsc/qingjian-translator/blob/v1.0.7/docs/verification/v1.0.7.md)。

## 安装与升级

下载附件 **qingjian-translator-v1.0.7.zip**，解压到固定目录。打开 Chrome 的 `chrome://extensions`，启用「开发者模式」，点击「加载已解压的扩展程序」，选择含 `manifest.json` 的目录。

已有用户覆盖原扩展目录后，在扩展管理页点击「重新加载」，并刷新已打开的网页或 YouTube 标签页。无须卸载，配置与历史统计保留。

## 使用边界

- 请求总预算仍按单个后台请求或批次计算，默认 90 秒，可调整为 30–300 秒；不代表整份文档的完成时限。
- 暂时错误的 3 次字幕会话尝试，每次可能包含后台既有的最多 3 次 HTTP 尝试，因此持续 503 的测试上限是 9 次 HTTP 请求。401 等永久配置错误不会进入该自动重试循环。
- 翻译调用最多等待统计记账 250 毫秒；统计待写队列上限为 32。极端存储故障时统计可能延迟或少记，不能作为账单；已启动的本地写入不能回滚。
- 本次验证使用本地模拟接口，未调用付费模型。客户端取消不能保证服务商停止计算或退费。
- 大 PDF 显示资源上限、在线文件下载大小和 EPUB 解压资源限制属于后续优化，不在本版修复范围内。
