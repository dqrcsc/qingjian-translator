# 青简 · 译读 v1.0.5

本版修复配置兼容与网页翻译生命周期中的 3 个问题，并修正补译导致的统计重复计数。

## 修复内容

- **协议配置正确兜底**：从原始存储配置确定协议，再合并默认值。未显式保存协议的 DeepSeek 等非 Google 配置不再被误判为 Gemini；自定义服务商明确选择的 Gemini/OpenAI 协议保持有效。前后台、配置保存和更新入口使用同一套规则。
- **快速开关不再丢段落状态**：段落重新进入观察阶段时即接管清理状态，旧的分帧清理不会删除新会话的待翻译段落。
- **取消后图片译文不再回弹**：图片解码完成后再次检查取消信号与任务身份；旧任务不能恢复覆盖层、清除新任务的加载状态或显示过期结果。
- **补译统计去重**：段落/字幕子集重试不再重复累计已译段落和源字符。例如 2 段中 1 段补译成功，累计完成仍为 2 段；子集补译批次另行记录。失败或补译期间取消不计成功产出，缓存命中不重复累计。

## 安装与升级

下载下方附件 **qingjian-translator-v1.0.5.zip**，解压到固定目录。在 Chrome 打开 `chrome://extensions`，启用「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。

已有用户将文件覆盖到原扩展目录后，在扩展管理页点击「重新加载」，并刷新已打开的网页或 YouTube 标签页。

## 使用说明

历史累计统计会保留；过去的重复计数无法自动准确还原，本次只修正后续计数。请求次数和字符数仍是应用估算，不代表服务商实际 Token 或费用。

测试使用本地模拟接口，未调用付费模型；音频用例验证协议准入，不代表真实录音和模型听译质量认证。客户端取消不保证服务商停止计算或退费，复杂 PDF 版式和 EPUB 资源保留仍有原有局限。
