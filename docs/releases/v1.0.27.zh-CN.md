# v1.0.27 · 网页译图悬浮交互优化

## 修复

- 修复网页插图与推文配图上的译图控制条（`🖼️ AI 译图` / 原位覆盖 / 对照 / 重译按钮）在挂载或完成翻译后常驻画面、遮挡图片内容的问题。控制条默认保持隐藏且不拦截鼠标点击，仅当指针悬停在目标图片、控制条本身、原位热区、双语对照抽屉或推文照片框内时显示，鼠标移出图片区域、滚出图片范围或离开页面后自动淡出隐藏。
- 修复点击译图按钮后焦点残留在按钮上导致鼠标移出图片仍不收起的问题：仅键盘焦点可见（`:has(:focus-visible)`）或图片翻译请求进行中保持控制条常驻可见，兼顾键盘无障碍操作与鼠标顺畅浏览。
- 按目标图片自身几何盒将控制条贴齐图片右上角，并为同一容器内的多张图片各自挂载独立控制条，避免鼠标移入 `<figcaption>` 图注或宽容器空白区时误触显示。
- 图片地址动态切换（`src` / `srcset` / `currentSrc` 变化）时保留当前悬停状态；在扩展设置中关闭「网页图片原位翻译」时，自动清理当前页面已挂载的译图控制条、原位覆盖层与双语对照抽屉。

## 交互与边界

- 隐藏态译图控制条关闭指针拦截与背景毛玻璃模糊，底层图片点击、右键菜单与链接跳转不受遮挡。
- 控制条新增按压微缩放反馈（`:active`）、键盘 `:focus-visible` 高对比度轮廓，并遵循系统 `prefers-reduced-motion: reduce` 减弱动画偏好。
- 网页译图仍受既有 20 MiB 图片体积上限与请求总时间预算约束；模型视觉识别与原位覆盖排版仍取决于图像清晰度及所配置模型能力。

## 安装

下载 `qingjian-translator-v1.0.27.zip`，解压后在 Chrome/Edge 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”。已有安装可替换文件后重新加载扩展，并刷新正在浏览的网页标签页。校验文件为同名 `.zip.sha256`。

## 验证范围

本地验收：48 项基础检查、261 项 Node 单元测试、201 项 Chromium 端到端回归全部通过，页面异常为 0。

覆盖网页未译与已译图片的真实鼠标悬停进入、移出图片区域收起、底层图片点击穿透、`<figcaption>` 图注隔离、同容器多图独立控制条、页面滚动离开图片自动隐藏及既有 PDF/EPUB/YouTube 全量回归。模型响应来自隔离本地测试服务，不代替真实外部模型识别质量验收；未提交 Chrome Web Store。详细结果见仓库 `docs/verification/v1.0.27.md`。
