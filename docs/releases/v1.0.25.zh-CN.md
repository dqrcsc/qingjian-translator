# v1.0.25 · 内容完整性与资源预算优化

## 修复

- PDF 提取保护图注上方的编号公式及分式上下标，结合正文判断单/双栏，避免公式进入图中文字覆盖流程、单栏图被错误裁成半栏。
- 图中文字清洗不再截断到 16 条，保留全部有效标签及其 HTML/打印输出。
- 未处理 PDF 不再下载空白 Markdown/EPUB；部分导出明确显示总页数、未处理/失败页及待处理图片，不自动启动额外翻译。
- YouTube 字幕轨不再在 20,000 条处截断，尾部字幕可搜索、跳转和导出，时间轴仍按窗口挂载。
- 划词语境围绕实际选区截取最多 600 字符，修复长段落末尾和重复词选区缺少所在句子的情况。

## 性能与可靠性

- 网络响应在流读取过程中执行字节预算：模型/列表 JSON 为 8 MiB，下载图片为 20 MiB。检查实际接收字节，支持无 Content-Length 或错误声明；超限立即取消且不重试。
- PDF 右侧阅读每组最多挂载 8 页，使用分组控件、目录或页码进入下一组。全文搜索和导出仍使用完整已处理数据，避免随着页数增长挂载全部右侧内容。
- 保留既有请求总时间预算、取消、左侧 PDF 渲染资源回收及未完成内容提示。
- 修复快速跨页后立即翻译可能遇到的取页竞态：旧渲染/取页取消尚未结束时有界等待资源交接，等待本身可取消；同时修复 PDF.js 流结束与取消竞态遗漏确认造成后续页面挂起的问题，补丁可复现且保留上游与修改后校验。

## 使用与边界

- 安装包是已解压扩展 ZIP：下载后解压，在 Chrome/Edge 扩展管理页开启开发者模式并选择“加载已解压的扩展程序”。已有用户替换文件后重新加载扩展，并刷新已打开的网页/YouTube 标签页。
- PDF 仍为尽力重排：复杂图框、未编号公式、混合矢量/位图标签需对照原 PDF。正文页完成不保证所有图中文字完成。
- 右侧分组限制的是 DOM，原始 PDF、已处理块和图像数据仍随文档体积增长；不宣称总内存恒定。
- 超大模型响应可能需要减少批次或更换输出设置；不要通过反复重试绕过字节预算。
- EPUB 保留文本、章节与目录重建，不保留原书完整图片、字体和 CSS。音频听译仍为 Gemini 原生协议的实验性切片能力。

完整验证结果见仓库 `docs/verification/v1.0.25.md`。本地模拟 API 验证协议、状态和数据完整性，不代替真实模型翻译质量评估。
