# 青简 · 译读 v1.0.6

本版重点改善慢请求的等待体验和长网页持续滚动时的资源回收，并修复动态替换图片后译图按钮仍引用旧图片的问题。

## 更新内容

- **请求总时间预算**：默认 90 秒，可在设置页调整为 30–300 秒。从后台收到单个请求起计时，排队、图片下载、响应体读取、重试等待、兼容接口回退和子集补译共用预算。超时会明确提示并停止后续请求，用户可以手动重试；原有单次尝试 45 秒上限保留。
- **长网页资源回收**：段落翻译成功或失败后释放内部记录；网页移除节点时解除观察，清理待发段落及相关引用，迟到结果不再写回已移除节点。连续滚动时不再持续积累已完成段落记录。
- **动态网页兼容**：同步移动 DOM 节点保留译文，移除后重新插入可以重新翻译；动态扫描合并为单个定时器，待扫描根集合超过 100 个时合并为文档根。
- **图片替换修复**：网页保留图片容器、只替换图片节点时，释放旧按钮、覆盖层及抽屉；新按钮绑定新图片，避免点击后仍操作旧图。

## 安装与升级

下载附件 **qingjian-translator-v1.0.6.zip**，解压到固定目录。在 Chrome 打开 `chrome://extensions`，启用「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的目录。

已有用户将文件覆盖到原扩展目录后，在扩展管理页点击「重新加载」，并刷新已打开的网页或 YouTube 标签页。已有配置和历史统计会保留，无须卸载扩展。

## 使用边界

总预算按单个后台请求或批次计算，不是整篇网页、整份文档的完成时限，也不包含前端图片解码时间。节点移除不会取消同一批次中其他仍有效的段落。超时后到达的模型结果不会写入缓存，但预算前已经启动的本地存储写入可能继续完成。

验证使用本地模拟接口，未调用付费模型。资源回收测试测量扩展持有的段落记录及观察目标，不代表整个浏览器堆内存归零。客户端中止 HTTP 请求不能保证服务商停止计算或退费。
