# 青简 · 译读 (QingJian) v1.0.18 发布说明

发布日期：2026-11-01

本版针对全量代码审查发现的商店上架阻塞项、后台安全边界、网页框架 DOM 兼容性、滚动扫描性能以及 Studio 文档工作台细节进行了系统修复与加固。

## 1. Chrome Web Store 合规与后台安全加固

- **商店元数据与隐私政策**：将 `manifest.json` 的 `description` 精简至 124 字符（符合 Chrome Web Store ≤132 字符限制），在 `web_accessible_resources` 中启用 `"use_dynamic_url": true`，并在仓库根目录新增中英双语 [PRIVACY.md](../../PRIVACY.md)。
- **管理接口特权发送方校验与防密钥泄露**：在 `background/service-worker.js` 中新增 `assertPrivilegedExtensionSender` 与 `mergeAdminTestSettings`，拦截普通网页 Content Script 调用 `TEST_API_KEY`、`FETCH_MODELS`、`CLEAR_CACHE` 等管理接口，并防止在覆盖 `apiBaseUrl` 时自动附带已存储的真实 `apiKey`。
- **快捷键动态注入兜底与缓存淘汰**：为 `Alt+A` / `Alt+S` 快捷键及右键菜单统一接入 `ensureContentScriptAndSendMessage`；为 IndexedDB 缓存补充连接关闭重连与 Service Worker 唤醒首次写入容量检查。
- **大模型客户端健壮性提升**：支持解析 `Retry-After` 响应头，收紧 `responseSchema` 降级条件并避免通用 HTTP 400 盲目重试，支持 `MAX_TOKENS` 批次自动对半拆分重试，为划词精解与输入框翻译开启 Flash `thinkingBudget: 0` 加速，对 OpenAI 推理模型（`o1`/`o3`/`o4`/`gpt-5`/`deepseek-reasoner`）自动省略 `temperature`，并为远程图片拉取增加协议、MIME 与 20MB 体积上限检查。

## 2. 网页内容脚本、YouTube 与 Studio 工作台修复

- **React/Vue 文本节点保护与扫描性能优化**：在取消网页翻译时移除 `el.normalize()`，仅合并扩展自身拆分的 `__igSplitFromPrev` 文本节点以保护现代前端框架的相邻文本节点边界；在单次 DOM 扫描中引入祖先可见性缓存 `activeScanVisibilityCache`，大幅减少重复 `getComputedStyle` 同步布局开销。
- **多语种识别与交互边界加固**：扩展 `isMostlyTargetLanguage` 与 `isForeignPageLikely` 支持日文、韩文、俄文及 `<html lang>` 检测；收紧 Alt 悬停翻译与三击空格对代码编辑器（CodeMirror / Monaco）及可编辑区域的过滤；处理 `pageshow` bfcache 恢复；YouTube 广告播放期间（`.ad-showing`）暂停正片字幕渲染与预取。
- **Studio 文档工作台加固**：移除多页 PDF 单页渲染为空时将整份 PDF 上传的危险回退，改为自动重试一次渲染并在失败时准确提示；通过 `inFlightPagePromises` 共享在途单页翻译 Promise；保护用户粘贴的附图（`userAttached: true`）不被整页重绘清除；剔除 EPUB 导出中的 XML 1.0 非法控制字符并限制 LaTeX 递归深度。
- **设置页与弹窗细节修复**：修复 `temperature = 0` 保存时被重置为 `0.2` 的问题，增加恢复默认配置二次确认、Popup 子域名后缀匹配与中文输入法 `isComposing` 回车过滤，并为深色界面声明 `color-scheme: dark`。

## 3. 验证与打包

- 新增 `tests/audit-fixes.test.mjs` 回归测试，通过 `npm run pack`（47 项扩展静态/行为校验 + 221 项单元测试 + 发布包完整性校验）。
