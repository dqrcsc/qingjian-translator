# 青简 · 津梁 v1.0.24

本版修复 v1.0.23 审查发现的七类问题，重点保护论文内容完整性，完善失败请求、图中文字补译和自动翻译规则的实际行为。

## 修复与改进

- **表格空值不再吞掉数据行**：不再仅凭空单元格合并前两行为表头，也不把空值擅自替换为横线。数据行与空值在提取、模型输入、阅读和导出中保持一致；多行表头缺少可靠依据时保留原始行。
- **位图图中文字有回退和明确状态**：文字层丰富的 PDF 页面仍优先文本翻译；已识别的插图缺少可用矢量标签时，尝试单图视觉识别。失败保留正文和原图，在进度、图上及 HTML/打印输出中提示未完成；可单独重试图中文字，无需重译正文。
- **页面失败及时收尾**：每个 PDF 页面使用独立请求组，某个文本批次失败时取消同页剩余排队和在途请求。暂停、换文档与关闭页面仍会取消全部相关任务。
- **裸公式正常渲染**：LaTeX 命令和环境名不再作为普通英文单词计数，修复裸分式、根号和矩阵被误当正文的问题。
- **站点规则入口一致**：网页抽屉和工具栏弹窗均显示继承的父域来源；取消时移除匹配的父域规则，影响其子站点。本次浏览器会话暂停仍通过翻译开关操作，不删除长期规则。
- **重连不重置总预算**：一次逻辑模型请求从首次发送起计时，自动重连仅使用剩余预算；预算到期后不再向模型重放请求。
- **说明与实现同步**：更新 PDF 导出提示、功能说明和密钥传递说明。PDF 为尽力重排；Gemini 的认证密钥使用 URL 查询参数，OpenAI 兼容协议使用认证请求头。

## 验证

- 48 项基础检查、231 个 Node 测试、177 项完整 Chromium 浏览器检查通过，页面异常为零。详细结果见 [v1.0.24 验收记录](../verification/v1.0.24.md)。
- 新增真实 PDF 上传测试：空单元格表格、Gemini 原生裸公式、文字层与嵌入 JPEG 图表混合页面、双协议单图识别、识别失败和单图恢复。
- 验证实际下载 HTML、打印媒体；保留既有生成 PDF 并重新读取的回归。并发为 1 和 3 时均验证失败后请求取消与手动重试。
- 真实 30 秒预算计时复验：第 25 秒断连后，约第 30 秒终止，不再像 v1.0.23 一样在第 35 秒返回成功。

## 安装与升级

下载 `qingjian-translator-v1.0.24.zip`，解压后在 Chrome/Edge 扩展管理页选择“加载已解压的扩展程序”。已有用户可更新原目录并点击“重新加载”，保留原配置。附件同时提供 SHA-256 校验文件。

升级前请先导出工作台中的重要文档；升级后刷新已有网页和 YouTube 标签页。未提交 Chrome Web Store 审核。

## 使用边界

- 视觉回退需要模型支持图片输入；纯文本模型可能返回不支持，扩展会保留原图并提示。当前回退针对已识别且缺少可用矢量标签的插图，不保证任意图框、复杂混合矢量/位图标签或所有公式都能准确还原。
- PDF 页数进度代表正文已处理页；另行提示尚未处理的图中文字。导出保留未完成提示，不自动保证整篇论文完整翻译。
- 总预算针对单个逻辑请求；一页可包含多个文本批次和图中文字请求，整页或整份文档不共用一个模型预算。浏览器中止 HTTP 不代表服务商必然停止计费。
- 回归使用原创合成 PDF、本地模拟接口及隔离浏览器，不代表所有真实论文与线上模型翻译质量均已验证。
