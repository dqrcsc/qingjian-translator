# v1.0.26 · 导出完整性与长文档阅读优化

## 修复

- PDF 打印使用独立快照，后台页面翻译成功、失败或同时下载 HTML 都不会覆盖已确认的打印范围；选定范围只构建所需页面。打印后释放快照，不切换阅读布局、搜索条件和页组。
- 修复只给未译 PDF 页附图时，Markdown/EPUB 错报全页已完成及 HTML 缺少正文未译提示的问题。附图仍可导出，但不代表正文已处理。
- 图中文字短标签不再仅对中文保留，西语、日语、阿拉伯语等目标语言的短词、缩写可正常覆盖和导出；纯数字/符号、重叠区域仍做过滤。识别到文字却没有可安全覆盖区域时明确提示重试。
- 划词精解校验非空译文、语境解释和词汇拆解；空对象、错误类型和无效 JSON 不再伪装成成功结果，也不累计成功段落及字符数，错误卡片提供重试按钮。
- Gemini 原生稀疏/扫描 PDF 提示词移除最多 10 条标签及英文来源限制，要求返回所有有效语种标签。模型实际漏识别仍可能发生，不保证视觉识别零遗漏。

## 性能与交互

- YouTube 一次字幕下载及格式回退共享 90 秒、8 MiB 预算，按实际流字节累计；同轨道并发请求合并。超限/空响应显示错误，支持手动重试，不发布截断字幕。
- 插件只取消自己发起的请求或自己的响应副本；不取消 YouTube 播放器原请求。播放器 XHR 已下载的内容只能在接收后检查大小，不控制播放器自身网络资源。
- PDF 目录每组最多显示 100 项；右侧阅读仍每组最多 8 页。点击页组按钮或输入组号时，页码和左侧原文同步到该组首个页面，保留搜索条件。
- HTML 在独立的脱离页面容器中生成，避免为了导出重建当前阅读区。打印图片准备最多等待 10 秒；导出期间阻止第二个 PDF 快照覆盖第一个。
- 已处理正文、译图、完整 HTML 和全篇 PDF 打印仍随文档规模占用内存；本版不承诺整篇数据或导出峰值恒定。

## 安装

下载 `qingjian-translator-v1.0.26.zip`，解压后在 Chrome/Edge 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”。已有安装可替换文件后重新加载扩展；刷新正在使用的网页及 YouTube 标签页。校验文件为同名 `.zip.sha256`。

## 验证范围

本地验收：48 项基础检查、260 项 Node 测试、200 项 Chromium 回归通过，页面异常为 0。

覆盖真实 PDF 上传、稀疏页 Gemini 协议、并发导出后重读 PDF、实际 HTML/EPUB 下载、多语言图标签、异常划词响应、目录/页组交互及 MAIN-world 字幕预算恢复。模型响应来自隔离本地测试服务，不代替真实模型翻译质量和任意论文版式验收；未提交 Chrome Web Store。详细结果见仓库 `docs/verification/v1.0.26.md`。
