# 青简 · 津梁 v1.0.23

本版修复 v1.0.22 浏览器回归失败，并完善学术 PDF 公式、表格与导出的一致性。

## 修复与改进

- **旋转页不再丢正文**：正常旋转 90° 的 PDF 页面曾被当作水印过滤，导致逐页翻译失败。现在保留正文，仅按明确的页边界与 arXiv 编号规则过滤水印。
- **规则表格保留行列**：`Method` 等表头不再因为命中章节标题关键词而阻止表格提取；有分列单元格的表头保持在表格中，表后正文仍是独立段落。
- **公式只显示一份**：本地识别的公式不需要再次翻译，现在正确记录为保留原文，避免双语模式重复展示或导出误标“未翻译”。
- **HTML 导出补齐学术样式**：根号横线、组合上下标、数学字形和作者卡片保持样式；双语、纯译文及打印均覆盖回归。
- **说明与实际路径对齐**：丰富文字层 PDF 在两种协议下均优先本地提取与分批文本翻译，Gemini 在文字层不足时才回退单页视觉分析；OpenAI 路径不自动对扫描件做 OCR。

## 验证

- 48 项基础检查、226 个 Node 测试。
- 169 项真实 Chromium 浏览器回归，覆盖旋转页、真实矢量 PDF 上传、OpenAI/Gemini 文本路径及 Gemini 多模态路径。
- 验证实际下载的 HTML、打印样式与生成的 PDF 文件，并重新读取打印 PDF 检查公式、表格及表后正文。
- 安装包按运行文件清单校验，并附 SHA-256 校验文件。

## 安装与升级

下载 `qingjian-translator-v1.0.23.zip`，解压后在 Chrome/Edge 扩展管理页选择“加载已解压的扩展程序”。已有用户可更新原目录并点击“重新加载”，无需卸载或清空配置。

请先导出正在处理的文档，升级后刷新已有网页和 YouTube 标签页。未提交 Chrome Web Store 审核。

## 使用边界

PDF 公式和表格使用坐标及文本规则尽力重建，不保证复杂合并单元格、嵌套公式或所有版式正确；请保留原 PDF 对照。请求预算针对每次后台请求，一页可能包含多个批次和图中文字请求，不能视为整页总时限。每批最多 3 段、按 900 字符目标分组，单个长段落保持完整。

回归使用原创合成 PDF 和本地模拟模型接口，不代表所有论文或真实模型翻译质量已经验证。详细证据见 [v1.0.23 验收记录](../verification/v1.0.23.md)。
