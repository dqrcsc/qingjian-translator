# v1.0.14 正确性修复设计

依据本轮 v1.0.13 审计和用户批准的六类修复、测试、推送及发布要求。基线 13cb1f0；版本 v1.0.14。沿用原生 ES Modules / MV3，不新增运行依赖，不实施审计中的大型资源优化。

## 行为与取舍

1. 内容脚本只发送白名单局部设置 PATCH；后台统一使用 saveSettings 的扩展源锁，回复不携带凭证。字段限制在样式、悬浮球位置及网页自动翻译规则。避免旧快照覆盖 popup/options。
2. PDF、图片响应由客户端做业务校验：文字块须有有效译文，code/equation 可保留原文；图片明确无文字允许成功，有文字而缺译/坏坐标应失败。无效结果不进入完成集合，不新增无限重试。
3. 翻译配置变化取消页面旧请求，移除旧译文，提示用户重新开启，避免静默产生整页重译费用。图片/划词/输入旧结果一并失效；YouTube 沿用既有自动恢复策略，补全语调/温度和模型配置字段。视觉样式与字号不触发翻译失效。
4. 链接属性变动同步译文安全链接，保留原节点关联或最小安全同步机制。只更新地址不重新调用模型；替换同文字链接和不允许协议都必须正确处理。
5. Markdown 导出为裸代码补足合法围栏，已有围栏保持；防内部反引号冲突。HTML/EPUB/MD 往返后代码不进入翻译请求。
6. 没有有效字幕禁止翻译和空导出，给出明确无字幕/格式提示；保留正常字幕入口和时间轴内容。

## 验证与发布

各模块补 Node 与真实浏览器入口回归；多模态覆盖 Gemini 原生异常响应、有效无文字图和公式页。设置竞争通过受控存储交错复现；旧配置晚响应不落地；实际导出文件重新读取/导入。运行全套 verify/browser、实际 ZIP 验证与解压入口 smoke。版本元数据、中文更新说明、校验文件一致后提交推送 main 与注解 tag；main/tag CI 成功后公开 GitHub Release。当前用户授权已涵盖修复方案与发布，无需额外确认。
