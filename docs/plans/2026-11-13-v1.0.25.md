# v1.0.25 实施与验收计划

用户已批准 v1.0.24 审查中的五项修复、两项资源优化及验证后推送发布。

设计：保留现有模块与协议；公式边界阻止图框吞并；有效标签和字幕不按固定条数丢弃；MD/EPUB 导出显示 PDF 覆盖范围；划词以 Range 定位上下文。网络响应流式计数，JSON 8 MiB、图片 20 MiB，超限取消且不重试。长 PDF 右侧每组最多 8 页，复用已有阅读分页，搜索按匹配页分组、目录/页码切组、导出绕过阅读窗口；保留完整块数据。

备选：无限制整区重建无法解决长文档 DOM 增长；连续滚动占位虚拟化需要高度测量和锚点恢复，当前选分组阅读以降低改动风险。拒绝以截断源内容换性能。

- [x] PDF：修改 studio/pdf-engine.js，保护编号公式和单栏插图范围、移除标签 16 上限。通过实际混合 PDF、17/20/50 标签、两协议及导出验证。
- [x] 导出：修改 studio/studio.js，无内容拒绝 MD/EPUB；部分 PDF 标出总页/缺页且不触发请求。真实下载验证。
- [x] 字幕与选区：修改 content/content-main.js，保留 20001 条轨道；Range 周围 600 字符，过滤生成节点；搜索/实际 SRT/HTTP 提示词验证。
- [x] 网络预算：background/gemini-client.js 流式字节计数，超限错误不重试；Node 覆盖边界/虚假长度/无长度/取消；浏览器两协议入口拒绝大响应后恢复。
- [x] PDF 阅读：studio/studio.js 复用分页，最多 8 页 DOM；搜索、页跳转、目录、卡片模式、HTML/打印全量互不截断。测量 50/200/500 页 DOM 和渲染，说明数据仍随文档增长。
