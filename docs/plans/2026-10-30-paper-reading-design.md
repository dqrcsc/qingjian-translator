# 论文阅读与站点临时暂停设计

用户确认：表格恢复规则行列、表格及公式采用柔和深青灰配浅灰底；手动关闭后，本次浏览器会话整个站点暂停自动翻译（包括新页面、新标签页），保留长期规则，手动开启恢复，浏览器重启恢复规则。已翻译的其他标签页不主动撤回。

## 论文内容

- `table` 类型的规则管道分隔文本（含 Markdown 分隔行、无分隔行的旧响应）渲染为安全 HTML table，保留单元格、表头、对齐、数学和粗体；列数不一致等无法可靠识别的内容保留全部原文，不能猜测错列或静默丢字。
- 多模态提示明确要求表格以规范 Markdown 表格返回，正文/表格数据类型仍沿用原有字符串协议，不增加模型字段或依赖。
- 白纸上的表格原文采用可读灰色，译文/公式深青灰 #335f65；浅灰底及细线保留区分。深色流式阅读采用柔和浅青灰。HTML 与打印导出同样保留表格结构和颜色，纯译文保持无原文。
- 不承诺从已丢失的模型文本重建复杂合并单元格或原 PDF 精确几何。

## 自动翻译暂停

- 暂停属于浏览器会话临时状态，后台使用 chrome.storage.session，不能写长期设置或仅放 service worker 内存。
- 站点按命中的 alwaysTranslateDomains 规则域名归组；无命中使用当前精确 hostname，不能把不同公共后缀站点误合并。
- 手动关闭记录暂停；手动开启及明确重新开启自动翻译规则解除暂停。首次自动启动先读暂停状态，已有页面的新自动行为也遵守；后台重启仍保留暂停。
- 全局自动翻译与自动打开 PDF 工作台都遵守暂停。明确点击翻译/PDF入口仍执行。已有完成译文和手动单段翻译不被全站撤销。
- 悬浮球/弹窗显示“本站本次会话已暂停”，说明手动开启恢复；失败保存需提示，不能伪称已持久化。
