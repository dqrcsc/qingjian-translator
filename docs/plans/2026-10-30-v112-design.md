# v1.0.12 正确性与阅读资源边界

用户已批准上一轮审计的 7 项修复，并授权验证后推送及发布 v1.0.12。本设计采用局部修补和有界窗口，不引入 UI 框架或全局重构；相比整体重写风险更低，相比只改提示能解决已复现行为。

1. 工作台把翻译配置绑定到文档。语言、协议、服务商、模型、接口、术语和提示变化时停止旧任务并提示；保留已有译文，用户可继续文档原配置或明确按新配置重译。后台模型执行与该快照一致，旧响应不能写入新代次。普通段落、单段、PDF 懒加载、图片和导出补译共用归属检查。
2. PDF 渲染限制单页边长和像素，按实际 scale 提取坐标；应用层画布缓存成本有明确上界。取消覆盖取页、渲染、取文本；失败释放画布，不能用无限 Promise.race 掩盖仍运行的 worker 任务。
3. 音频切片使用实际媒体起止时间；暂停、seek、倍速变化结束或废弃旧片段并隔离晚到响应。暂停不忙录音，停止释放所有监听与计时器。
4. 字幕列表用户手动滚动后停止自动跟随，提供返回当前句按钮；程序跳转不误判为手动，搜索保持位置，关闭重开/导航释放状态。
5. 长文档采用有界段落分页/窗口，保持完整数据模型和导出；搜索去抖。优先明确的分页导航以降低动态高度虚拟化复杂性，纯译文、章节、定位、局部翻译仍可用。PDF 右栏和原 PDF 内部内存不是此项常数内存承诺。
6. 文案统一为按协议/模型能力可用、实验性 7 秒切片听译、尽力保持版式与覆盖图片文字，去除结构化输出 100% 合法承诺。

验收：上述审计复现必须转为故障回归；真实扩展入口覆盖配置切换/续译/重译、尺寸受限 PDF、取消后后续页、手动字幕阅读、媒体时间变化与完整字幕导出、万段文档分页/搜索/全宽/完整导出。执行 verify、完整 Chromium、pack 和解压安装冒烟；主分支与标签 CI 通过后发布中文说明、ZIP 和 SHA-256。
