# v1.0.14 Implementation Plan

> **For agentic workers:** Execute independent modules with delegated workers and integrate in this session. The optional superpowers execution skills are not installed; use the available collaboration tools and explicit verification checkpoints.

**Goal:** 修复 v1.0.13 审计的六类问题，验证并发布 v1.0.14。

**Architecture:** 后台串行设置写入；客户端边界校验；内容脚本配置失效和链接语义同步；工作台格式序列化与空导入反馈。保持当前模块边界。

**Tech Stack:** MV3、原生 JS ES Modules、Node test、Playwright/Chromium。

**Spec:** `docs/plans/2026-10-30-v114-design.md`

## Global Constraints

- 基线 13cb1f0；发布 v1.0.14；不新增运行依赖。
- 不批量删除文件，不修改无关模块，不请求真实服务商密钥。
- 产品代码不加入测试专用入口；浏览器使用真实入口和本地 HTTP 模型服务。
