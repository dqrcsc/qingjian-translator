# v1.0.12 Implementation Plan

**Goal:** 修复审计 7 项，验证真实入口后发布 v1.0.12。
**Architecture:** 保留原生 ES Modules，配置归属、PDF 资源、YouTube 时序与文档分页分别测试。按 writing-plans 的分任务方式执行独立实现与集成检查。
**Tech Stack:** JavaScript、Chrome MV3、Node test、Playwright、PDF.js。
**Spec:** docs/plans/2026-10-30-v112-design.md

## Global Constraints

- 不删除用户成果、不批量删除文件，不引入框架，不重写无关模块。
- 发布版本 v1.0.12；所有模型测试仅用本地 fixture。

## Tasks

- [ ] 配置归属：studio/studio.js、background/service-worker.js。新增快照/签名与失配提示；显式新配置重译取消旧代次；后台使用文档快照。用三段 Markdown 先中文后英语的真实入口验证不静默混用，再覆盖 PDF/单段/导出。
- [ ] PDF：studio/pdf-engine.js，tests/pdf-render-budget.test.mjs，浏览器 fixture。执行原函数的过大 viewport/三阶段取消探针，新增尺寸预算和生命周期处理；验证坐标、并发与迟到结果。
- [ ] YouTube：content/content-main.js 与测试。保存录制结束的媒体时间，注册 pause/seeking/ratechange 边界和清理；时间轴手动模式及返回当前句。回归 2 倍速 100–114 秒字幕、手动滚动下一句保持位置、完整导出。
- [ ] 正文窗口：studio/studio.js/html/css，tests 与 browser scripts。正文和左大纲最多一页 100 段；分页、搜索重置范围、目录定位和完整模型导出。导入万段，搜索远处并翻页、纯译文和导出全部内容。
- [ ] 文案：README、CHROMEWEBSTORE、对应按钮/帮助文案；说明实际边界，不添加无法保证的指标。
- [ ] 集成：npm run verify、npm run test:browser、npm run pack、解压加载冒烟、git diff --check。记录验收与已知边界。
- [ ] 发布：版本文件、CHANGELOG、中文说明；提交、annotated tag、atomic push；检查 CI，上传 ZIP/SHA256，公开 v1.0.12 Release 并核对资产摘要。
